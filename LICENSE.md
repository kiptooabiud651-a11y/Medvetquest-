# Contributing to MedVet Quest & Clinical Academy

We welcome contributions, bug fixes, quiz questions, and feature enhancements from the medical and veterinary student community!

## How to Contribute
1. Fork the repository.
2. Create a new branch for your feature (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add new veterinary pharmacology quiz module'`).
4. Push to your branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.
