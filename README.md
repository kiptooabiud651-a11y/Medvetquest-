# MedVet Quest & Clinical Academy 🩺🐾

An interactive, gamified educational platform built for both **Human Medicine (MD/DO)** and **Veterinary Medicine (DVM)** students. 

##  Key Features
- **Dual-Track Curriculum:** Seamlessly switch between human and veterinary medicine (covering canine, feline, equine, bovine, and avian species).
- **Core Disciplines:** Structured modules in Anatomy & Histology, Physiology & Biochemistry, Microbiology & Immunology, Pharmacology & Therapeutics, Pathology & Pathophysiology, and Surgery & Anaesthesiology.
- **Clinical Case Simulator:** Interactive patient intake, real-time vital telemetry monitoring, diagnostic testing (labs, imaging, cultures), differential diagnosis matrix, and emergency treatments.
- **Board Review Quizzes:** Test your knowledge with multi-disciplinary multiple-choice questions and instant rationales.
- **Gamification & Cloud Sync:** Level up, earn XP, maintain daily streaks, and sync your progress securely.

##  Built With
- Pure HTML5, CSS3, and JavaScript
- Tailwind CSS / Custom UI Styling
- Web Audio API (for sound effects and alerts)
- Firebase Auth & Firestore (for cloud data persistence)
- Progressive Web App (PWA) ready
